# 🏥 Clínica de Fisioterapia

Sistema web para gestión de reservas de citas en clínica de fisioterapia.

## 🚀 Tecnologías

(Versiones de ejemplo)

- **Backend:** Java 17 + Spring Boot 3.2
- **Frontend:** Vue.js 3 + Vite
- **Base de Datos:** PostgreSQL 15
- **Metodología:** SCRUM
